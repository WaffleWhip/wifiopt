wifiopt — pipeline (per-baris tree)
═══════════════════════════════════

mysql ── discover_interference_reborn_<date>_reg<N>
│
├─ [1] parse (per region, per band)
│   │
│   ├─ input row
│   │   ├─ CPE_Serial_Number ───────────→ sn
│   │   ├─ json_config["<slot>"].bssid ─→ own_bssid
│   │   ├─ json_config["<slot>"].channel → own_ch
│   │   ├─ json_config["<slot>"].possible_channel (csv) → own_possible_ch
│   │   ├─ json_neighbor["<slot>"].bssid ────────→ neighbor_bssid
│   │   ├─ json_neighbor["<slot>"].channel ──────→ neighbor_ch
│   │   └─ json_neighbor["<slot>"].signal_strength → neighbor_rssi
│   │
│   ├─ split by band
│   │   ├─ 2g: own_ch 1..13, slot 1..4
│   │   └─ 5g: own_ch >=36, slot >=5
│   │
│   └─ filter: drop bssid == "00:00:00:00:00:00"
│
├─ [2] cluster (per band: 2g | 5g)
│   │
│   ├─ build own_set = union(all own_bssid)
│   │
│   ├─ for each ap, filter neighbors
│   │   ├─ if neighbor_bssid ∈ own_set ─→ keep
│   │   └─ else ────────────────────────→ drop
│   │
│   ├─ DSU joint
│   │   ├─ node "s:<sn>"
│   │   ├─ node "b:<bssid>"
│   │   ├─ union "s:<sn>" ↔ "b:<own_bssid>"
│   │   └─ union "s:<sn>" ↔ "b:<filtered_neighbor_bssid>"
│   │
│   └─ output: ClusterResult.valid
│       ├─ sorted by cluster_size ASC (singleton → 2 → 3 → ...)
│       ├─ entry: ([SNs], [BSSIDs])
│       │   ├─ size 1 (singleton, no neighbors)
│       │   ├─ size 2
│       │   └─ size N (incl monster cluster 136k)
│       └─ min_size filter: keep clusters where |SNs| >= min_size
│
├─ [3] optimize (per band)
│   │
│   ├─ input
│   │   ├─ MemRow per AP (sn, own, neighbors, own_ch, possible_ch)
│   │   ├─ clusters from [2]
│   │   └─ max_idle_rounds from config.json (default 50)
│   │
│   ├─ loop until converge (counter reset on movement)
│   │   │
│   │   ├─ for cluster in clusters (sorted cluster_size ASC)
│   │   │   │
│   │   │   └─ for ap in cluster (sorted sn_link ASC = degree ASC)
│   │   │       ├─ degree 1 → process & lock
│   │   │       ├─ degree 1 → process with context
│   │   │       ├─ degree 2 → process with context
│   │   │       └─ degree N → process with full context
│   │   │
│   │   └─ per ap, pick best channel
│   │       ├─ possible_channels_for(ap, band)
│   │       │   ├─ 2g: STRICT [1, 6, 11]
│   │       │   └─ 5g: non-DFS ∩ ap.possible_channel
│   │       │
│   │       └─ evaluate cost via channel_cost_with_assignment
│   │           ├─ nb_ch = assigned.get(nb_bssid) ?? neighbor.static_ch
│   │           └─ cost += overlap(cand, nb_ch) × type × rssi × owner
│   │
│   ├─ termination
│   │   ├─ if changed: counter = max_idle_rounds (RESET)
│   │   ├─ else: counter -= 1
│   │   └─ stop when counter == 0 OR !changed
│   │
│   └─ snapshot
│       ├─ cost_before = Σ cost when all APs at ch_before (initial)
│       └─ cost_after  = Σ cost when all APs at ch_after (final)
│
└─ output: TSV → stdout (13 cols, MySQL-compatible)
    │
    ├─ columns
    │   ├─ reg, sn
    │   ├─ clusterid_2g, ch_before_2g, cost_before_2g
    │   ├─ ch_after_2g, cost_after_2g, status_2g
    │   ├─ clusterid_5g, ch_before_5g, cost_before_5g
    │   └─ ch_after_5g, cost_after_5g, status_5g
    │
    ├─ constraints
    │   ├─ clusterid_X = sequential int per region, NULL for singleton
    │   ├─ ch_after_2g ∈ {1, 6, 11}
    │   ├─ ch_after_5g ∈ non-DFS only
    │   ├─ status = "CHANGE" if ch_after != ch_before else "STAY"
    │   └─ NULL → "\N" (MySQL convention)
    │
    └─ example row
        reg3  SN1  1  8  1.2345  11  0.4500  CHANGE  \N  \N  0.0000  \N  0.0000  STAY
